## Verified findings

1. **Canonical origin is correct.** www is canonical; apex 308s; sitemap
   locs and homepage canonical agree (no slash on `/`).
2. **Brand on the live homepage is CD Sportswear INC.** Runtime JS/JSX
   contains no `CD Sportswear USA` string. Asset filenames
   (`cd-sportswear-usa-logo.png`) remain historical URL-stable names.
3. **Public IA** (from `app/sitemap.js` + `lib/servicePages.mjs`): `/`,
   `/work` + 6 case studies, `/services` + 8 services (web-design,
   web-development, branding, logo-design, digital-marketing, animation,
   ai-automation, workflow-automation), `/about`, `/process`, `/contact`,
   `/reviews`, `/blog` + published posts from Supabase, `/privacy`,
   `/terms`, `/embroidery-screen-printing-web-design`.
4. **CRM is noindex + robots-disallowed.** `/login` and `/signup` are
   indexable by MJ (2026-09-11) but are correctly omitted from the sitemap.
5. **JSON-LD exists** on the homepage (Organization + WebSite +
   AggregateRating from the 20 published reviews), service pages (Service,
   FAQPage, BreadcrumbList), work (CreativeWork), blog (Blog / BlogPosting).
   Organization `name` is `CD Sportswear INC`. `sameAs` is empty until real
   profiles exist.
6. **Inner marketing pages do not mount the homepage WebGL journey.** They
   use `IdleScene` — intentional, not a regression to remove.
7. **Lighthouse 2026-09-03 is historical**, not current. Homepage mobile
   perf 34 / LCP 13.5s on that run. Not re-measured this pass (no
   Lighthouse in this environment). Do not treat those scores as live.
8. **Shopify landing is not justified.** Live services do not include
   Shopify. Keyword est. 880/mo at diff 8 remains attractive, but a hire
   page would be a thin URL for an unsold offer. Parked.

## Inferred findings

- Blog markdown in Supabase may still contain absolute apex / retired-domain
  hrefs (the 2026-09-10 run noted domain-move residue). `toSitePath` is the
  runtime guard; the table itself was not dumped this run.
- Organization `address` for Manassas, VA and Sharjah, AE matches `SITE.city`
  / `SITE.citySecondary`. Treated as legitimate current NAP because
  `lib/site.js` is the studio's declared source of truth; no third-party
  business listing was checked.
- AggregateRating on the root Organization node is backed by `/reviews`
  (20 reviews, average 4.3). Google may still prefer Review nodes on the
  same URL; that is existing architecture, left alone.
