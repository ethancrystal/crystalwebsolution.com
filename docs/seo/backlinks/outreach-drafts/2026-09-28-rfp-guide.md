and warns that an account "may be shut down without warning" on complaint or
bounce thresholds. The same Resend account is the CRM's transactional sender
(`lib/email/resend.js`: auth links, invites, password resets, notifications),
so a suspension would break production sign-in. Outreach goes from the real
`sales@cdsportswearinc.com` mailbox by hand. (`cdsportswearinc.com` IS a
verified Resend sending domain and the domain HAS MX records on
`secureserver.net`, so the mailbox exists — the block is the policy, not the
plumbing.)
