# User Journey: Client Collaboration lifecycle

## User Persona
* **Who**: Active client coordinating a project with Crystal Web Solution.
* **Goal**: Collaborate with the CWS team, view progress, and approve deliverables.
* **Context**: Checked on both desktop and mobile throughout the week.

---

## Journey Stages

### Stage 1: Onboarding (Incoming Client)
* **What user is doing**: Completing the initial signup on CWS portal, requesting staff access if they are project managers, or receiving an admin invite link.
* **What user is thinking**: "How secure is this portal? Where do I see my project workspace?"
* **What user is feeling**: 🤩 Excited but anxious to start.
* **Pain points**:
  - Unclear role assignment details.
* **Opportunity**: Automatically direct clients to a welcoming onboarding wizard dashboard indicating next actions.

### Stage 2: Workspace Setup & Discovery
* **What user is doing**: Accessing `/dashboard`, reading project brief, exploring initial milestones.
* **What user is thinking**: "Where is the contract? Who is my point of contact?"
* **What user is feeling**: 😌 Reassured by the clean design.
* **Pain points**:
  - Missing team information or contact guidelines.
* **Opportunity**: Show dedicated "Your Project Team" card with quick action buttons.

### Stage 3: Active Collaboration (Continuous Delivery)
* **What user is doing**: Checking real-time project state, downloading work-in-progress artifacts, uploading assets, and submitting feedback/approvals.
* **What user is thinking**: "What is my team working on today? Are they waiting on me for anything?"
* **What user is feeling**: 🤝 Engaged, collaborative, and informed.
* **Pain points**:
  - Not knowing which files require immediate action.
  - Large file upload limitations.
* **Opportunity**: Implement progress trackers and a clear "Needs Your Action" flag on specific project attachments.

### Stage 4: Project Sign-Off
* **What user is doing**: Reviewing final project deliverables, verifying contracts, and executing handoff.
* **What user is thinking**: "Everything looks ready. How do we launch?"
* **What user is feeling**: 🎉 Accomplished and ready to refer CWS.
* **Success metrics**:
  - Handoff completed on schedule.
  - 100% of attachments signed off within the portal.
