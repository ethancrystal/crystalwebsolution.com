# Topic library — starter prompts for GNZ blogs

A working library of blog topics organized by service line, format, and funnel stage. Use this when the user says "write a GNZ blog about something" without specifying. Pick a topic that hasn't been done; cross it off this list (or mark it in your tracking) after publishing.

Each topic includes the target keyword, recommended format, and recommended funnel stage. Not every topic on this list should be written — pick based on what GNZ has actually delivered for clients (real case studies, real frameworks) so the post has substance behind it.

## Seasonal / news-pegged opportunities

These should be written near the timing trigger, not in advance.

- **Black Friday / Q4 e-commerce playbook** — September publication for November traffic
- **New year / new fiscal year planning** — December–January
- **Tax season for accountants / financial advisors** — February
- **Back to school** — July–August
- **Google Algorithm updates** — within 7 days of confirmation
- **Major platform changes** (Meta Ads API change, Google SGE rollout, Apple privacy changes) — within 14 days of news

## How to pick

If the user says "write a GNZ blog about [topic]" — pick the format that matches the keyword intent.

If the user says "write a GNZ blog" with no topic — propose 3 from this list, weighted toward:
1. Topics where GNZ has real client work to back the post
2. Topics with strong target keywords that GNZ doesn't yet rank for
3. Topics aligned to the current quarter's lead-generation priority

If the user has already written posts that overlap with topics here, mark those overlaps so you don't pitch redundant ideas. Track published posts in a separate `published.md` file (create on first publication) so the library stays useful as the blog grows.
